HearthLedger is the Hartley family's zero-based household budget: an offline, static site with an Overview dashboard, envelope budget planner, shared transactions ledger, bills and due dates, and savings goals — all working from local files with no network requests. Built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Overview, Budget Envelopes, Transactions, Bills & Due Dates, and Savings Goals, with demo data for November 2026 already in place. Add a transaction, mark a bill paid, or move an envelope slider and every total updates at once. Data lives only in the browser (localStorage); Reset demo data restores the original month.
